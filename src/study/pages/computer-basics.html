Computer and DEST · Tier-II Computer Knowledge (qualifying)

Computer basics

Computer Knowledge is a qualifying section of Paper-I. The marks are not added to the merit of most posts, but you must clear the standard the Commission sets, and some posts have a higher standard. The basics are the machine itself: processor, memory, and the devices you touch.

Fifteen minutes and twenty questions is a speed test of facts you either know or do not. Short revisions beat a long textbook the night before.

What SSC lists

  • Organisation of a computer, CPU, input and output devices.
  • Computer memory, memory organisation, backup devices and ports.
  • Windows Explorer and keyboard shortcuts at a basic level.
  • The section is mandatory and qualifying. Para 13.9.9 of the 2026 notice is the rule.

Rules and formulas

CPU

The CPU has an arithmetic logic unit, which calculates and compares, a control unit, which directs the other parts, and registers, which hold the tiny working values.

Memory

RAM is volatile: it loses its contents when power goes. ROM is non-volatile.
In the binary count used in these questions, 1 byte = 8 bits, and 1 KB = 1024 bytes.
Cache is a small fast memory close to the CPU. A hard disk or SSD is secondary storage, not RAM.

Devices and ports

Keyboard, mouse, scanner and microphone are input devices. Monitor, printer and speaker are output devices.
USB and HDMI are ports. A pen drive is a backup or transfer device, not a port.

Explorer

Windows Explorer, now often called File Explorer, is the program used to view files and folders.
A folder holds files. A file has a name and an extension that hints at its type.

Common traps

RAM is not permanent storage. Switching the computer off clears it.

The printer is an output device. The scanner is an input device. A touchscreen can be both, and a question that says “both” is then the careful answer.

1 KB in this exam’s usual arithmetic is 1024 bytes, not 1000.

The control unit does not do the arithmetic. The ALU does.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
Which memory loses its contents when power is switched off?

  1. ROM
  2. RAM
  3. A CD already written
  4. A printed page

Solution

  1. RAM is volatile.
  2. ROM keeps its stored program without power.

Answer: B. Secondary storage also keeps its contents. The volatile one in the options is RAM.

Example 2
The part of the CPU that performs calculations is the

  1. control unit
  2. arithmetic logic unit
  3. monitor
  4. port

Solution

  1. ALU stands for arithmetic logic unit.
  2. The control unit manages the steps. It does not add the numbers.

Answer: B. The monitor only displays a result.

Example 3
Which of these is an input device?

  1. Printer
  2. Speaker
  3. Scanner
  4. Monitor

Solution

  1. A scanner sends a picture into the computer.
  2. Printer, speaker and monitor send something out.

Answer: C. If the option list includes a touchscreen, read whether the question allows a device that does both.

Example 4
In the binary count used for these questions, 1 KB equals

  1. 8 bytes
  2. 100 bytes
  3. 1024 bytes
  4. 1024 bits

Solution

  1. 1 byte = 8 bits.
  2. 1 KB = 1024 bytes.

Answer: C. 1024 bits would be 128 bytes, a different quantity.
