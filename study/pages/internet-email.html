Computer and DEST · Tier-II Computer Knowledge (qualifying)

Internet and email

This slice is the ordinary web: a browser, an address, a search, a download, and an email account. The questions separate words that everyday speech mixes up, especially browser and search engine, and website and web page.

E-banking appears in the syllabus as a use of the network. Treat it as a secure login on a bank’s own site, not as a password sent by mail.

What SSC lists

  • Web browsing and searching.
  • Downloading and uploading.
  • Managing an email account.
  • E-banking as a use of the internet, at a basic level.

Rules and formulas

Browser and search

A browser is the program: Chrome, Firefox, Edge.
A search engine is a service you visit, such as a search page, which looks through an index of the web.
A website is a collection of pages. A web page is one of those pages.

Address

A URL is the address of a resource.
HTTP is the ordinary transfer protocol. HTTPS is the version that encrypts the traffic.
A domain name is translated to a numeric address by DNS.

Mail

To is the main recipient. CC is a copy that everyone can see. BCC is a copy hidden from the other recipients.
Sending mail uses SMTP in the usual textbook account. Receiving uses POP or IMAP.

Up and down, and banking

Download: from the network to your computer. Upload: from your computer to the network.
E-banking means using the bank’s authenticated online service. Do not share the password or the OTP.

Common traps

A browser is not a search engine. You use a browser to open a search engine.

HTTPS is not a guarantee of an honest seller. It means the connection is encrypted.

BCC is hidden. CC is not.

Download and upload are opposite directions. Check which way the file moves.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
Which of these is a web browser?

  1. A search results page by itself
  2. Google Chrome
  3. SMTP
  4. RAM

Solution

  1. Chrome is the application that displays pages.
  2. A search page is a site you open inside a browser.

Answer: B. SMTP is a mail protocol and RAM is memory.

Example 2
HTTPS differs from HTTP because HTTPS

  1. cannot open a page
  2. encrypts the connection
  3. is an email folder
  4. is a type of RAM

Solution

  1. The S stands for secure in the usual expansion.
  2. The traffic is encrypted.

Answer: B. Encryption does not by itself prove that the organisation at the other end is trustworthy.

Example 3
BCC in an email means

  1. a public copy
  2. a hidden copy
  3. the subject line
  4. an attachment

Solution

  1. CC is the visible copy.
  2. BCC is the blind, hidden copy.

Answer: B. People on the To and CC lines do not see the BCC names.

Example 4
Moving a file from a website onto your computer is

  1. uploading
  2. downloading
  3. scanning
  4. formatting

Solution

  1. The file comes down to you.
  2. That is a download.

Answer: B. Uploading would send your file out to a server.

  1. translate a domain name to an address
  2. print a slide
  3. delete RAM
  4. bold a word

SMTP is associated with

  1. sending email
  2. displaying a monitor image only
  3. a keyboard port
  4. a spreadsheet chart
Show answer

Answer: A. It is the simple mail transfer protocol, used for sending.

Practice 3
The address of a page on the web is a

  1. URL
  2. CPU
  3. ALU
  4. ROM
Show answer

Answer: A. URL: uniform resource locator, the address.

Practice 4
An OTP for e-banking should be

  1. shared in a reply to any mail that asks
  2. kept private and entered only on the bank’s own login
  3. posted on a public page
  4. used as your permanent password for every site
Show answer

Answer: B. The OTP is a secret for that transaction. A mail asking you to send it is a common fraud.
