Quantitative Aptitude · Tier-I and Paper-I

Algebra, surds and linear graphs

School algebra in this paper is a small set of identities, a pair of linear equations, and surds that simplify by taking squares out of the root. A graph question usually asks where the line cuts an axis, not for a long plot.

If a + b + c = 0, the cube identity collapses. That one line is worth remembering.

What SSC lists

  • Basic algebraic identities of school algebra.
  • Elementary surds.
  • Graphs of linear equations, including intercepts.
  • Simple equations in one or two variables that come out of those identities.

Rules and formulas

Squares and cubes

(a+b)² = a² + 2ab + b².
(a−b)² = a² − 2ab + b².
a² − b² = (a−b)(a+b).
(a+b)³ = a³ + 3a²b + 3ab² + b³.
a³ + b³ = (a+b)(a² − ab + b²).
a³ − b³ = (a−b)(a² + ab + b²).
If a + b + c = 0, then a³ + b³ + c³ = 3abc.

Reciprocal

If x + 1/x = k, then x² + 1/x² = k² − 2.
And x³ + 1/x³ = k³ − 3k.

Surds

√(a²×b) = a√b when a is positive.
√18 = 3√2 and √8 = 2√2.
To rationalise 1/(√a + √b), multiply by √a − √b.

Line

For ax + by = c, the y-intercept is the value of y when x = 0.
The x-intercept is the value of x when y = 0.
Two different lines meet at one point unless they are parallel.

Quick methods

Put values: if an identity holds for all values, test the options at an easy value such as a = 1, b = 0.
x − 1/x = k gives x² + 1/x² = k² + 2.
If x + 1/x = 2 then x = 1, so xⁿ + 1/xⁿ = 2 for every n.
a² + b² = (a + b)² − 2ab.
If a + b + c = 0, (a³ + b³ + c³)/abc = 3.
For y = mx + c the slope is m and the y-intercept is c.

Pair of lines

a₁x + b₁y = c₁ and a₂x + b₂y = c₂.
One solution: a₁/a₂ ≠ b₁/b₂.
No solution (parallel): a₁/a₂ = b₁/b₂ ≠ c₁/c₂.
Infinitely many (same line): a₁/a₂ = b₁/b₂ = c₁/c₂.

Common traps

(a+b)² is not a² + b². The middle term 2ab is the usual miss.

If a + b + c = 0, you do not expand the cubes one by one.

√18 + √8 is 5√2, not √26.

The intercept is a coordinate. “Cuts the y-axis at 6” means the point (0, 6).

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
If (a+b)² = 49 and (a−b)² = 9, then ab is

  1. 8
  2. 10
  3. 12
  4. 20

Solution

  1. Subtract: (a+b)² − (a−b)² = 4ab.
  2. 49 − 9 = 40 = 4ab.
  3. ab = 10.

Answer: B. You can also add the two equations to get 2(a²+b²) = 58, but the product only needs the subtraction.

Example 2
If x + 1/x = 5, then x² + 1/x² is

  1. 21
  2. 23
  3. 25
  4. 27

Solution

  1. Square both sides: x² + 2 + 1/x² = 25.
  2. x² + 1/x² = 25 − 2 = 23.

Answer: B. The cross term from the square is 2, not 0.

Example 3
If a + b + c = 0, and a = 1, b = 2, c = −3, then a³ + b³ + c³ is

  1. 0
  2. 6
  3. −6
  4. −18

Solution

  1. When a + b + c = 0, the sum of cubes is 3abc.
  2. 3 × 1 × 2 × (−3) = −18.
  3. Directly: 1 + 8 + (−27) = −18.

Answer: D. The identity is the fast route; the direct sum is the check.

Example 4
The solution of 2x + 3y = 12 and x − y = 1 is

  1. x = 2, y = 3
  2. x = 3, y = 2
  3. x = 4, y = 3
  4. x = 1, y = 2

Solution

  1. From the second equation, x = y + 1.
  2. 2(y+1) + 3y = 12, so 5y + 2 = 12 and y = 2.
  3. x = 3.

Answer: B. 2(3) + 3(2) = 12, and 3 − 2 = 1.

Example 5
√18 + √8 equals

  1. √26
  2. 5√2
  3. 10√2
  4. √10

Solution

  1. √18 = √(9×2) = 3√2.
  2. √8 = √(4×2) = 2√2.
  3. Sum = 5√2.

Answer: B. You can add surds only after the number under the root matches.

Example 6
(CGL pattern) For what value of k do 3x + 5ky − 7 = 0 and x + y − 4 = 0 have no solution?

  1. 3/5
  2. 5/3
  3. 7/4
  4. 1/3

Solution

  1. No solution needs 3/1 = 5k/1.
  2. k = 3/5.
  3. Check the constants: 7/4 ≠ 3, so the lines are parallel, not the same.

Answer: A. If the constants also matched, there would be infinitely many solutions.

Example 7
(CGL pattern) If x² + y² = 52 and xy = 24 with x > y > 0, then (x − y)/(x + y) is

  1. 1/2
  2. 1/5
  3. 2/5
  4. 5

Solution

  1. (x − y)² = 52 − 48 = 4, so x − y = 2.
  2. (x + y)² = 52 + 48 = 100, so x + y = 10.
  3. Ratio = 2/10 = 1/5.

Answer: B. x = 6 and y = 4 confirm it.

Example 8
(CGL pattern) The area of a square is 9x² + 24x + 16. Its perimeter is

  1. 4(3x + 4)
  2. 2(3x + 4)
  3. 3(4x + 3)
  4. 4(4x + 3)

Solution

  1. 9x² + 24x + 16 = (3x + 4)².
  2. Side = 3x + 4. Perimeter = 4 × side.

Answer: A. Spot the perfect square: first term (3x)², last term 4², middle 2 × 3x × 4.
