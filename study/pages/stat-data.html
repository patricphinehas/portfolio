Statistics (Paper-II) · Tier-II Paper-II, JSO and Statistical Investigator only

Collection and presentation of data

Paper-II is graduation-level statistics, and only candidates shortlisted for Junior Statistical Officer or Statistical Investigator Grade-II write it. This first page is how data are collected and shown. Paper-I’s chart reading is the school version. Here the names are more precise.

Primary data are collected by you for this enquiry. Secondary data were collected by someone else, and you are using them.

What SSC lists

  • Primary and secondary data, and methods of collection.
  • Tabulation.
  • Graphs, charts and frequency distributions.
  • Diagrammatic presentation of frequency distributions.

Rules and formulas

Sources

Primary data: collected for the present enquiry, by census, sample, observation or questionnaire.
Secondary data: already collected, such as a government report. They save time and may not match your definitions.

Frequency

A frequency distribution lists classes and how many observations fall in each.
Class width should be consistent unless the question builds an unequal scheme on purpose.
The midpoint of a class is (lower limit + upper limit) / 2.

Pictures

A histogram uses adjoining rectangles for continuous classes. A frequency polygon joins class midpoints.
A bar diagram is for categories and has gaps. An ogive is a cumulative-frequency curve.

Tables

A good table has a title, clear stubs and captions, units, and a total where a total makes sense.
A two-way table classifies by two factors at once.

Quick methods

Inclusive classes 10–19, 20–29: boundaries are 9.5–19.5, 19.5–29.5 (subtract and add half the gap).
Frequency density = frequency / class width. Use it for histogram heights when widths differ.
Relative frequency = class frequency / total.
Pie angle of a class = frequency / total × 360°.

Common traps

Primary does not mean “more important”. It means collected first-hand for this study.

A histogram is not a bar chart. The bars of a histogram touch.

The midpoint is not the class width.

An ogive plots cumulative frequency, not the raw frequency of one class.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
Data collected by an investigator for the present study are

  1. secondary
  2. primary
  3. always a census of the world
  4. an ogive

Solution

  1. First-hand collection for this enquiry is primary.
  2. A published report used afterwards would be secondary.

Answer: B. The cost and the fit to your definitions are the practical difference.

Example 2
The midpoint of the class 10–20 is

  1. 10
  2. 15
  3. 20
  4. 30

Solution

  1. Add the limits and divide by 2.
  2. (10 + 20) / 2 = 15.

Answer: B. The width is 10. The midpoint is 15.

Example 3
A histogram is suitable for

  1. a continuous frequency distribution
  2. a list of unrelated country names with gaps as the point
  3. a single total only
  4. a probability axiom

Solution

  1. Continuous classes are shown by adjoining rectangles whose areas represent frequency.
  2. Separate categories are a bar diagram.

Answer: A. If the class widths differ, the height must be adjusted so that area, not height alone, carries the frequency.

Example 4
An ogive is a graph of

  1. cumulative frequency
  2. only the mode
  3. a regression line
  4. a pie of profits

Solution

  1. Cumulative frequency is plotted against the class boundary.
  2. The curve is the ogive.

Answer: A. A frequency polygon uses the class frequencies themselves, not the running total.

Practice yourself

Attempt these without opening the answer. Then check the toggle.

Practice 1
Secondary data are

  1. collected for the first time for this enquiry
  2. already collected by someone else
  3. always wrong
  4. the same as a histogram
Show answer

Answer: B. You use an existing source.

Practice 2
Class width of 20–30, in a continuous equal-width scheme, is

  1. 10
  2. 25
  3. 50
  4. 5
Show answer

Answer: A. 30 − 20 = 10, when the classes are set that way.

Practice 3
Bars separated by gaps are typical of

  1. a histogram of a continuous variable
  2. a bar diagram of categories
  3. an ogive
  4. a scatter of two variables
Show answer

Answer: B. Categories are separate. A histogram’s rectangles touch.

Practice 4
A table that classifies students by both class and gender is

  1. a one-way table
  2. a two-way table
  3. an ogive
  4. a mean
Show answer

Answer: B. Two factors of classification.

Practice 5
In the inclusive series 10–19, 20–29, …, the boundaries of 20–29 are

  1. 20–29
  2. 19.5–29.5
  3. 19–30
  4. 20.5–28.5
Show answer

Answer: B. Half the gap of 1 is 0.5.

Practice 6
A class 10–30 has frequency 40. Its frequency density is

  1. 2
  2. 4
  3. 20
  4. 40
Show answer

Answer: A. 40/20 = 2.

Practice 7
A class has frequency 30 out of 120. Its pie-chart angle is

  1. 30°
  2. 60°
  3. 90°
  4. 120°
Show answer

Answer: C. 30/120 × 360 = 90°.
