Computer and DEST · Tier-II Computer Knowledge (qualifying)

Operating system and MS Office

The software line of the syllabus is Windows and the three Office tools: Word, Excel and PowerPoint. Questions are about what each program is for, and about a handful of shortcuts and Excel rules.

A formula in Excel starts with an equals sign. A shortcut that works in Word often works in the other two, but a few are special to Excel.

What SSC lists

  • Windows operating system.
  • Basics of MS Word, MS Excel and PowerPoint.
  • Keyboard shortcuts.
  • The difference between system software and an application.

Rules and formulas

Windows

An operating system manages hardware, files and the programs you run. Windows is system software in that sense.
An application, such as Word, does a user job on top of the operating system.

Shortcuts

Ctrl+C copy, Ctrl+X cut, Ctrl+V paste, Ctrl+Z undo, Ctrl+Y redo, Ctrl+A select all, Ctrl+S save, Ctrl+P print, Ctrl+F find.
In Word, Ctrl+B is bold, Ctrl+I italic, Ctrl+U underline.

Excel

A formula begins with =.
=SUM(A1:A5) adds that range. =AVERAGE(A1:A5) averages it.
$A$1 is an absolute reference: it does not shift when the formula is copied. A1 is a relative reference, and it does shift.

PowerPoint

A presentation is made of slides. A slide can hold a title, text and a picture.
The slideshow is the way the slides are shown in order.

Common traps

Ctrl+X is cut, not paste. Ctrl+V is paste.

A formula without the equals sign is stored as text and is not calculated.

$A$1 does not change when copied. A1 does.

Word is not the operating system. Windows is.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
The shortcut for paste is

  1. Ctrl+C
  2. Ctrl+X
  3. Ctrl+V
  4. Ctrl+Z

Solution

  1. Ctrl+C copies and Ctrl+X cuts.
  2. Ctrl+V pastes.
  3. Ctrl+Z undoes.

Answer: C. Think of the three as copy, cut, paste, in the order C, X, V.

Example 2
In Excel, which entry is a formula?

  1. SUM(A1:A3)
  2. A1+A2
  3. =A1+A2
  4. Total A1

Solution

  1. A formula starts with =.
  2. Only =A1+A2 will be calculated.

Answer: C. The others are text or a label.

Example 3
Ctrl+B in Word makes the selection

  1. italic
  2. bold
  3. underlined
  4. saved

Solution

  1. B stands for bold.
  2. Italic is Ctrl+I and underline is Ctrl+U. Save is Ctrl+S.

Answer: B. The letter matches the word.

Example 4
An absolute cell reference is written as

  1. A1
  2. A1:A5
  3. $A$1
  4. A$ only in the name box with no cell

Solution

  1. The dollar signs lock the column and the row.
  2. $A$1 is the absolute form.

Answer: C. A1 will change if you fill the formula down or across.
