Reasoning · Tier-I and Paper-I

Syllogism and conclusions

A syllogism gives statements that you must take as true, then asks which conclusion has to follow. Draw the smallest Venn diagram that fits the statements. A conclusion follows only when it is true in every diagram the statements allow.

“All A are B” is drawn as the A circle inside the B circle. In the method used for these papers, that also supports “Some A are B” and “Some B are A”. A conclusion that is only possible, not necessary, does not follow.

What SSC lists

  • Statement and conclusion.
  • Syllogistic reasoning with All, Some, No, and Some not.
  • Two statements and two conclusions, which is the usual form.
  • The same circles appear again on the Venn diagram page, there as a picture of real groups.

Rules and formulas

Standard drawings

All A are B: A inside B.
No A is B: A and B do not touch.
Some A are B: the circles overlap.
Some A are not B: at least part of A lies outside B.

What follows

A conclusion follows only if every allowed drawing makes it true.
If one allowed drawing makes it false, it does not follow.

From All

From “All A are B”, these papers also accept “Some A are B” and “Some B are A”.
From “All A are B” and “All B are C”, “All A are C” follows.

Possibility

If the question asks what is possible, a single drawing that fits is enough.
If it asks what follows, possibility is not enough.

Common traps

“Some A are B” does not mean “Some A are not B”. Both can be true, but neither is forced by the other.

“No A is B” does not by itself decide the link between A and C.

Do not use outside knowledge. If the statement says all cats are birds, draw it that way.

A conclusion that fits one diagram and fails another does not follow.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
Statements: All cats are dogs. All dogs are animals. Which conclusion follows?

  1. No cat is an animal
  2. All cats are animals
  3. No dog is an animal
  4. Some cats are not animals

Solution

  1. Draw cats inside dogs, and dogs inside animals.
  2. Then every cat is inside animals.
  3. All cats are animals.

Answer: B. “Some animals are cats” also follows, but it is not among the options.

Example 2
Statements: All pens are books. Some books are papers. Which conclusion follows?

  1. Some pens are papers
  2. All papers are pens
  3. No pen is a book
  4. None of these necessarily follows

Solution

  1. Pens sit inside books.
  2. Papers only overlap books. That overlap may miss the pens.
  3. “Some pens are papers” is possible, not necessary.

Answer: D. No listed positive link between pens and papers has to be true.

Example 3
Statements: No A is B. Some B are C. Which conclusion follows?

  1. No A is C
  2. Some C are not A
  3. All C are A
  4. Some A are C

Solution

  1. The B’s that are C cannot be A, because no A is B.
  2. Those C’s are therefore not A.
  3. “Some C are not A” must be true. “Some A are C” need not be.

Answer: B. The definite piece is the part of C that lies in B.

Example 4
Statements: All A are B. All B are C. Which of these follows?

  1. Some C are A
  2. No C is A
  3. No A is C
  4. Some A are not C

Solution

  1. A is inside B, and B is inside C.
  2. So some of C, namely the A part, is A.
  3. Some C are A.

Answer: A. All A are C also follows. The negative options contradict the drawing.

Example 5
(CGL pattern) Statements: Some apples are fruits. All fruits are sweets. Conclusions: I. Some apples are sweets. II. All sweets are fruits. III. Some sweets are apples.

  1. Only I and III follow
  2. Only I follows
  3. All follow
  4. Only II follows

Solution

  1. The apples that are fruits are inside sweets, so I follows.
  2. III is the reverse of I, so it follows too.
  3. II reverses an ‘All’, which is not allowed.

Answer: A. “Some A are B” always gives “Some B are A”.
