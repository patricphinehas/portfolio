Computer and DEST · Tier-II Computer Knowledge (qualifying)

Networking and cyber security

The syllabus names networking devices and protocols, and the threats: hacking, virus, worm, Trojan, and the measures taken against them. The words are more important than a network diagram.

A virus, a worm and a Trojan are not three names for the same thing. The difference is how they arrive and how they spread.

What SSC lists

  • Basics of networking and cyber security.
  • Devices and protocols.
  • Threats: hacking, virus, worms, Trojan and related frauds.
  • Preventive measures such as a firewall, updates and careful habits.

Rules and formulas

Networks

LAN: a small local area, such as an office. MAN: a city. WAN: a wide area, across cities or countries.
A router forwards packets between networks. A switch connects devices inside a local network.

Protocols

TCP/IP is the pair of protocols the internet is built on in these questions.
HTTP and HTTPS move web pages. FTP moves files. SMTP sends mail.

Threats

A virus attaches to a host file and typically needs a user action to spread.
A worm spreads by itself across a network, without needing to attach to a host file.
A Trojan looks like useful software and hides a harmful payload.
Ransomware locks data and demands payment. Phishing tricks you into giving away a password, often by a fake message.

Defence

A firewall filters traffic. Updating the system and not opening unexpected attachments are the practical measures.
An antivirus looks for known malicious software. It is not a reason to click every link.

Common traps

A worm is not “a virus that only attacks email” in the textbook contrast. The textbook contrast is self-spreading.

HTTPS encrypts. It does not make a phishing site honest.

LAN is local, WAN is wide. Do not swap them.

A firewall is not the same object as an antivirus, even though both are defences.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
A program that spreads across a network by itself, without attaching to a host file, is a

  1. worm
  2. Trojan horse only
  3. firewall
  4. router

Solution

  1. That description is the worm.
  2. A Trojan relies on being installed because it looks useful.

Answer: A. A firewall would be a defence, not the spreading program.

Example 2
Phishing is

  1. a hardware port
  2. an attempt to trick a person into revealing secret information
  3. a type of RAM
  4. a spreadsheet function

Solution

  1. The attack is social as much as technical.
  2. A fake message asks for a password or an OTP.

Answer: B. The defence is to check the real address and not to send the secret.

Example 3
Which network covers the smallest typical area?

  1. WAN
  2. MAN
  3. LAN
  4. The public internet as a whole

Solution

  1. LAN is local.
  2. MAN is metropolitan and WAN is wide.

Answer: C. The internet is a network of networks, far larger than a LAN.

Example 4
Ransomware

  1. speeds up the CPU
  2. locks data and demands payment
  3. is a keyboard shortcut
  4. is an input device

Solution

  1. The name comes from the ransom.
  2. The files are encrypted or locked until money is demanded.

Answer: B. Paying is not a repair method this page recommends. The practical lesson is backup and not opening the payload.
