Reasoning · Tier-I and Paper-I

Coding and decoding

Coding hides a word by a fixed rule: shift the letters, reverse them, add their alphabet positions, or swap the code symbols. The notice also names small and capital letters used as codes.

Decode the rule from the given pair. Then apply that same rule. Do not switch rules halfway through the word.

What SSC lists

  • Coding and decoding of letters and numbers.
  • Small and capital letters used as a code.
  • Symbolic operations, when a sign is redefined. Those mixed-sign sums are practised on the word-building page as well.
  • A short alphabet position list: A=1, Z=26, and the opposite pairs A-Z, B-Y, C-X.

Rules and formulas

Shift

A +1 shift sends each letter to the next letter. CAT becomes DBU.

Positions

A=1, B=2, … Z=26.
The sum of positions is a common number code.

Opposites

The opposite of a letter is the letter equally far from the other end.
A pairs with Z, B with Y, C with X, and M with N.

Reverse then shift

If the example reverses the word and then shifts, do both steps, in that order.

Common traps

A code built on one example may fit two rules. Use a second coded word if the question gives one.

Opposite-letter coding is not the same as a +1 shift.

Capital and small letters sometimes mark two different shifts. Read the case before you add.

When you add positions, write the numbers. GREEN is not “about 50”.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
If CAT is coded as DBU, then DOG is coded as

  1. EPH
  2. CPF
  3. ENF
  4. FQH

Solution

  1. Each letter is increased by 1.
  2. D→E, O→P, G→H.

Answer: A. CAT→DBU confirms the same shift.

Example 2
If RED is coded as 27 by adding letter positions, GREEN is coded as

  1. 44
  2. 47
  3. 49
  4. 56

Solution

  1. R=18, E=5, D=4, and 18+5+4 = 27.
  2. G=7, R=18, E=5, E=5, N=14.
  3. 7+18+5+5+14 = 49.

Answer: C. The same addition rule, not a shift.

Example 3
If each letter is replaced by its opposite letter, CAT is coded as

  1. XZG
  2. XZU
  3. YGZ
  4. DBU

Solution

  1. C is opposite X, A is opposite Z, T is opposite G.
  2. CAT becomes XZG.

Answer: A. Opposite pairs: A-Z, C-X, T-G.

Example 4
In a code, STAR is first reversed and then each letter is increased by 1. The code is

  1. SBUT
  2. RATS
  3. TUBS
  4. UTBS

Solution

  1. STAR reversed is RATS.
  2. R+1=S, A+1=B, T+1=U, S+1=T.
  3. The code is SBUT.

Answer: A. Reversing alone would leave RATS, which is the unfinished step.

Example 5
If APPLE is coded as 50 by letter positions, then CAT is coded as

  1. 24
  2. 27
  3. 30
  4. 54

Solution

  1. A=1, P=16, P=16, L=12, E=5. Sum = 50, so the rule is addition.
  2. C=3, A=1, T=20.
  3. 3+1+20 = 24.

Answer: A. Check the given word before using the rule on CAT.

Example 6
(CGL pattern) In a code language, ‘sun is hot’ is ‘ka lo mi’ and ‘hot tea cup’ is ‘pa mi zu’. The code for ‘hot’ is

  1. ka
  2. lo
  3. mi
  4. zu

Solution

  1. ‘hot’ is the only word in both sentences.
  2. ‘mi’ is the only code in both.

Answer: C. Match the common word with the common code.

Example 7
(CGL pattern) In a code, LAMP is written as 4729 and CAMP as 7291, with the digits in jumbled order. The code for C is

  1. 1
  2. 4
  3. 7
  4. 9

Solution

  1. A, M and P are common, and so are 7, 2 and 9.
  2. L goes with the leftover 4, and C with the leftover 1.

Answer: A. Cancel the common letters and common digits.

Example 8
(CGL pattern) The letters of FOREST are arranged in alphabetical order. How many letters of the English alphabet lie between the second letter from the left and the second from the right in the new arrangement?

  1. 11
  2. 12
  3. 13
  4. 14

Solution

  1. Alphabetical: E F O R S T.
  2. Second from left is F (6). Second from right is S (19).
  3. Between them: 19 − 6 − 1 = 12.

Answer: B. Count letters strictly between, so subtract 1.

  1. 7
  2. 9
  3. 11
  4. 15

Answer: B. 1+3+5 = 9.

Practice 4
If a word is reversed and no other change is made, DRAW becomes

  1. WARD
  2. XBSE
  3. ARDS
  4. RWAD
Show answer

Answer: A. The letters in reverse order are W, A, R, D.

  1. DIBJS

Practice 6
If A = 2, B = 4, C = 6 (twice the position), DOG is

  1. 26
  2. 48
  3. 52
  4. 56
Show answer

Answer: C. D = 8, O = 30, G = 14. Sum 52.

Practice 7

  1. YZT
  2. CBH

  4. XZT
Show answer

Answer: A. B↔Y, A↔Z, G↔T. Each pair adds to 27.
