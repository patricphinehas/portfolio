Reasoning · Tier-I and Paper-I

Analogy

An analogy says that two pairs share the same link. Your job is to name the link in the first pair, then apply that same link to the second pair. The link may be meaning, letters, or numbers.

Say the link in a short sentence before you look at the options. “Hospital is where a doctor works” is a link. “Both start with D” is usually a trap.

What SSC lists

  • Semantic analogy: words and their meanings.
  • Symbolic and number analogy.
  • Figural analogy, where the second figure is the first figure after one change.
  • The same links appear inside classification and series, so the habit transfers.

Rules and formulas

Word link

Name the relation: tool and use, worker and workplace, animal and young, degree of a quality, part and whole.

Number link

Test +n, ×n, n², n²+n, n³, and n³+1 before anything more complicated.

Letter link

Use A=1 … Z=26 only after a meaning link fails.
A shift of +1 turns CAT into DBU.

Figures

One change only: rotation, reflection, added side, or shaded region. Apply that one change to the next figure.

Number sets

For a set like (a, b, c), find one rule that turns a and b into c, then apply the same rule to each option.
Try sum, difference, a + b ± k, 2a + b, a × b ÷ k, a² ± k. Use whole numbers, not their digits, when the question says so.

Common traps

Do not invent a second link if the first pair already has a clear one.

4:16 can be “square” or “×4”. Check the second pair before you choose.

A workplace analogy fails if the option is only related by topic and not by the same relation.

In a figural item, a rotation and a reflection are different. Check which way the shape faces.

Worked examples

Read the solution only after you have tried the question. Options are in exam style.

Example 1
Doctor is to hospital as teacher is to

  1. book
  2. student
  3. school
  4. chalk

Solution

  1. A doctor works in a hospital.
  2. A teacher works in a school.
  3. Book, student and chalk are related, but they are not the workplace.

Answer: C. Keep the relation “professional : workplace”.

Example 2
4 : 20 :: 6 : ?

  1. 30
  2. 36
  3. 42
  4. 48

Solution

  1. 4 × 5 = 20, and 5 is one more than 4.
  2. The same link is n × (n+1).
  3. 6 × 7 = 42.

Answer: C. 36 is 6², which is a different link and does not fit 4:20.

Example 3
Pen : write :: knife : ?

  1. cut
  2. sharp
  3. steel
  4. kitchen

Solution

  1. A pen is used to write.
  2. A knife is used to cut.

Answer: A. Sharp and steel describe the knife. They are not the action.

Example 4
If CAT is written as DBU, then DOG is written as

  1. EPH
  2. CPF
  3. EOH
  4. FQI

Solution

  1. Each letter moves one step forward.
  2. D→E, O→P, G→H.
  3. DOG becomes EPH.

Answer: A. The same +1 link that turned CAT into DBU.

Example 5
Book : author :: statue : ?

  1. stone
  2. sculptor
  3. museum
  4. clay

Solution

  1. An author creates a book.
  2. A sculptor creates a statue.

Answer: B. Stone is the material, not the maker.

Example 6
(CGL pattern) Select the set related in the same way as (12, 18, 50).

  1. (8, 14, 40)
  2. (20, 5, 40)
  3. (10, 15, 45)
  4. (9, 11, 38)

Solution

  1. 12 + 18 + 20 = 50. The rule is a + b + 20.
  2. 10 + 15 + 20 = 45 fits.
  3. The others give 42, 45 and 40, not the third number.

Answer: C. Test the rule on every option before choosing.

Example 7
(CGL pattern) 15 is related to 228 and 9 is related to 84 by the same logic. 12 is related to

  1. 144
  2. 147
  3. 150
  4. 156

Solution

  1. 228 = 15² + 3. 84 = 9² + 3.
  2. 12² + 3 = 147.

Answer: B. 144 is the square alone, missing the + 3.

Example 8
(CGL pattern) Scarce : Abundant. Select the pair with the same relationship.

  1. Brave : Courageous
  2. Ancient : Modern
  3. Rapid : Quick
  4. Silent : Quiet

Solution

  1. Scarce and abundant are opposites.
  2. Ancient and modern are opposites. The other pairs are synonyms.

Answer: B. Name the relation, antonym, before scanning the options.

Example 9
(CGL pattern) Figure 1 is related to Figure 2. In the same way, Figure 3 is related to which option?

Solution

  1. Figure 2 is Figure 1 turned 90° clockwise.
  2. Turn the flag 90° clockwise: the pole lies flat and the flag points down.

Answer: B. A is the turn the other way, C is a mirror image, D is a half-turn.

Practice 1
Cow : calf :: horse : ?

  1. foal
  2. puppy
  3. kid
  4. lamb
Show answer

Answer: A. The young of a horse is a foal. A calf is the young of a cow.

Practice 2
9 : 81 :: 7 : ?

  1. 42
  2. 49
  3. 56
  4. 63
Show answer

Answer: B. The link is the square. 7² = 49. It also fits 9:81.

Practice 3
Eye : see :: ear : ?

  1. sound
  2. hear
  3. ring
  4. head
Show answer

Answer: B. The eye is used to see. The ear is used to hear.

Practice 4
AB : CD :: EF : ?

  1. FG
  2. GH
  3. HI
  4. IJ
Show answer

Answer: B. Each letter of the first pair is shifted +2. E+2 = G and F+2 = H.

Practice 5
Bird : nest :: bee : ?

  1. hive
  2. honey
  3. flower
  4. wing
Show answer

Answer: A. Home of the creature.

Practice 6
3 : 27 :: 5 : ?

  1. 25
  2. 75
  3. 125
  4. 15
Show answer

Answer: C. Cube: 5³ = 125.

Practice 7
Author : book :: composer : ?

  1. orchestra
  2. music
  3. piano
  4. singer
Show answer

Answer: B. Creator and what is created.
