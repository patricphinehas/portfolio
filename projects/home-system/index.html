Home System

Self-hosted household operations for inventory, grocery bills, spend analytics, and a shared family calendar.

What it covers

Seven modules, from what is on the shelf to a calendar the household shares.

01

Overview

Stock counters and a Buy next list when items hit their minimum. An item is low when its quantity is at or below that minimum.

02

Inventory

Category tabs, tags, and purchase history per item.

03

Bills

Per-unit pricing (kg, litre, piece) with a comparison to past purchases.

04

Analytics

Monthly spend, projections, deviations, and inflation.

05

Calendar

Shared events, RSVPs, bookings, and comments.

06

MCP

Household data as MCP tools, plus chat through Ollama, NVIDIA NIM, or OpenRouter.

07

Settings

Profile, region, database, inference engine, and theme.

How it is built

Next.js 16 serves the pages. Express is the data API. DB_SELECT in .env chooses MongoDB or Postgres. Postgres can be a Supabase-compatible database through DATABASE_URL.

The browser talks only to Next.js on port 3000. Next rewrites /api to Express on port 4000, and Express is the only process that talks to the database. Nothing is read from or written to disk at runtime.

Architecture, the API, and the pricing maths are written up in the project docs.

Run it locally

Use mise, or install Node 24 and pnpm 12 yourself. You also need MongoDB or Postgres.

  1. Copy .env.example to .env.
  2. Set DB_SELECT to mongodb or supabase and fill in the matching connection settings.
  3. Install, check, migrate, seed, and start the app.
mise run setup      # toolchain + dependencies, creates .env if missing
mise run doctor     # check Node, pnpm, packages, the selected database, ports
mise run migrate    # Postgres schema, or Mongo indexes
mise run seed       # inventory, demo bills, subscriptions and calendar
mise run develop    # pages on :3000, data API on :4000

Without mise:

pnpm install
pnpm run doctor    # this project's checks, not pnpm's built-in doctor
pnpm migrate
pnpm seed
pnpm dev
pnpm check

The app needs a reachable database. Until you seed, an empty database shows an empty UI.
